# Data Center Lab
Welcome to my repository, created for practicing and learning one of **the profession of the future**. 

This repository will serve as an archive of my practical studies and incidents during my path.

Hands-on lab to build the skills of a Data Center Technician: server maintenance, storage (RAID), networking and troubleshooting.

Each lab is documented as a short ticket: context, actions,
verification, issues and lessons learned.

## Environment
- Ubuntu 24.04 LTS server installed on a ORACLE VirtualBox VM (4 GB RAM, 2 vCPU, 25 GB disk)
- NAT networking, SSH access via port forwarding
- Markdown documentation, version control with Git
