# 2026-10-23 - System update on srv-lab-01

**Context:** VM not updated since June 2026 (last login 15/06).

**Before:** Ubuntu 24.04.4 LTS, kernel 6.8.0-124-generic.

**Safety:** VirtualBox snapshot "PreUpdate23/10" (VM powered off).

**Actions:**
```bash
sudo apt update
sudo apt full-upgrade
sudo reboot
```

**Verification:** `uname -r` = 6.8.0-147-generic, `systemctl --failed` = 0 loaded units listed.

**Issues:** Using `apt list --upgradable` before `apt update` shows no update because the update list was outdated.

**Lessons learned:**
   - A snapshot (taken with the VM off) gives a fast rollback if the update breaks something. It is not a backup!
   - `apt update` refreshes the package list; `apt full-upgrade` installs the updates.
   - The kernel runs from RAM, so a reboot is required to load the new one.

**Next steps:**
   - Use the VM for a few days, then delete the snapshot.
   - Replace the expired GitHub token with an SSH key.
